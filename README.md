## Documents hérités de l'organisation

Ces fichiers sont fournis par le dépôt
[`.github`](https://github.com/tozano-data-labs/.github) et s'appliquent par défaut :

- `CONTRIBUTING.md`
- `SECURITY.md`
- `CODE_OF_CONDUCT.md`
- `SUPPORT.md`
- `PULL_REQUEST_TEMPLATE.md`

Le handbook approfondit ces règles ; en cas de divergence, le dépôt `.github`
fait foi pour les règles de gouvernance.
