# ADR 0001 — Utiliser des ADR

- **Statut** : accepté
- **Date** : 2026-11-07

## Contexte

Les choix techniques structurants doivent rester traçables et compréhensibles
dans le temps.

## Décision

Toute décision structurante est consignée dans un ADR sous `docs/adr/`.

## Conséquences

- Les PR qui introduisent une décision structurante référencent un ADR.
- Les ADR acceptés ne sont pas modifiés ; ils sont remplacés.
