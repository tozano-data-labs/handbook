# RGPD et données personnelles

## Principes

- **Minimisation** : ne collecter que les données nécessaires.
- **Finalité** : chaque jeu de données a un usage documenté.
- **Conservation** : une durée de rétention est définie et appliquée.
- **Droits des personnes** : accès, rectification, effacement.

## Règles pour les dépôts

- Aucune donnée personnelle réelle dans les exemples, tests ou seeds.
- Les données d'exemple sont publiques ou synthétiques.
- Les journaux et prompts ne contiennent pas de données personnelles.
- Tout traitement de données personnelles est documenté dans `docs/rgpd/`.

## Checklist avant livraison

- [ ] Données personnelles identifiées
- [ ] Base légale et finalité documentées
- [ ] Durée de conservation définie
- [ ] Moyens d'exercice des droits prévus
- [ ] Aucune donnée réelle dans le dépôt

En cas de doute, signaler le point comme bloquant avant de livrer.
